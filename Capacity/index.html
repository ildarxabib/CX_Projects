Как работает расчёт

Квартальное планирование

Tier S · активная фаза245 ч

Базовая полезная мощность CJE — 375 часов на квартал. Для Tier S эксперт выбирает фазу при заведении задачи: активная списывает 245 часов, пассивная — 115 часов. Для остальных Tier режим не меняет квартальный тариф.

Недельный срез

TierДиапазон → расчёт / пассивно
Tier 03% / —
Tier 121% / —
Tier 225–40% → 32% / 14%
Tier S35–50% → 42% / 17%

Калькулятор использует середину диапазона: 32% для активного Tier 2 и 42% для активного Tier S. Это даёт одну понятную цифру для решения; суммирование широких диапазонов затруднило бы оценку свободного слота. Рекомендация «Tier 2 активно» появляется при остатке от 32%, «Tier S активно» — от 42%. Пассивный режим: нет активных действий 3+ рабочих дня, следующее действие ожидается не раньше чем через 3 дня.
